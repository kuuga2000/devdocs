Command Reference

A curated list of essential commands for development and deployment.

Git Version Control

git init

Initialize a brand new local repository in the current folder.

git add .

Stage all changed files in the current directory for the next commit.

git commit -m "msg"

Record your changes to the repository history with a descriptive message.

Terminal Navigation

ls

List all files and directories in the current folder.

cd [folder]

Change directory to the specified path.

mkdir [name]

Create a new folder with the specified name.
